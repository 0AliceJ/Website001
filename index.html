Types of Colour Values

Red Green Blue: (red channel, green channel, blue channel) (values from 0 to 255)

rgb(255, 99, 71)

Hexadecimal: #rrggbb (values from 00 to ff, 0 to 9 -> a -> f)

#ff6347

Hue Saturation Lightness: (hue channel, saturation channel, lightness channel) (hue values from 0 to 360, other values from 0% to 100%)

hsl(9, 100%, 64%)

RGBA: (red, green, blue, alpha channel) (alpha values from 0.0 to 1.0)

rgba(255, 99, 71, 0.8)

HSLA: (hue, saturation, lightness, alpha channel) (alpha values from 0.0 to 1.0)

hsla(9, 100%, 64%, 0.3)
